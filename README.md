**"비즈니스의 성장을 이끄는 튼튼한 데이터 파이프라인을 짓습니다."**

자바 백엔드(APM) 엔지니어로 커리어를 시작해, 현재는 대규모 데이터의 흐름을 제어하는 **데이터 엔지니어**로 일하고 있습니다. 
단순한 파이프라인 구축을 넘어, 치열한 운영 환경 속에서 터지는 병목 현상을 트러블슈팅하고 **'100% 신뢰할 수 있는 데이터 정합성'**을 맞추는 일에 집착합니다. 시키는 대로 개발하기보다 프로덕트의 생애주기를 함께하며 데이터 마트에 주도적인 오너십을 갖는 것을 지향합니다.

### 💡 What I Do
- **Data Engineering:** Apache Spark, Flink, Airflow를 활용한 대용량 분산 처리 및 이벤트 드리븐 파이프라인 설계
- **Data Reliability:** 실시간/배치 데이터 정합성 보장 및 현업 친화적인 데이터 마트(SCD 등) 모델링
- **Troubleshooting:** AWS EKS(Kubernetes) 환경에서의 OOM, Data Skew 최적화 및 SLA 방어 로직 구현
